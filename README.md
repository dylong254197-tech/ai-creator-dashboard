# AI Creator Efficiency Dashboard

> **为AI创作者设计的Notion命令中心。4个互联数据库，17个预建视图，5分钟导入。**

---

## 你的AI工作流需要这个

每天在ChatGPT、Claude、Midjourney之间切换，项目散落在不同工具里，好的Prompt用完就忘——

这个Notion模板解决最核心的三个问题：

**集中管理**: 任务、内容、AI对话、知识库——一个工作区装下所有
**不丢好Prompt**: 所有AI对话自动存档，评分+分类，再也不会"上次那个Prompt怎么写的来着"
**一键调度**: 按能量级别安排任务，看板/日历/表格视图一键切换

## 包含什么

| 数据库 | 用来做什么 | 预建视图数 |
|--------|-----------|-----------|
| 📋 Task Tracker | 管理所有创作任务，按优先级和能量级别调度 | 5 |
| 📅 Content Calendar | 规划YouTube/博客/播客等内容管线 | 4 |
| 💬 AI Chat Log | 存档AI对话，按工具/用例/评分分类 | 4 |
| 📚 Knowledge Base | 保存最佳Prompt和AI洞察，与对话关联 | 4 |

**共17个视图，4个数据库互联，5分钟导入即用。**

### 数据库如何协作

```
Task Tracker ↔ Content Calendar    任务直接关联内容排期
AI Chat Log  → Knowledge Base      把对话中的最佳Prompt保存为知识
```
